## 摘要
视觉-语言-动作（VLA）模型能够提供广泛的、以指令为条件的操作行为，但在接触密集的交互过程中，其物理执行仍可能不够精确。残差强化学习（RL）可以在保持 VLA 冻结的同时纠正此类误差，然而真实机器人上的 RL 成本高昂且对安全性要求极高。我们提出 VLA 潜在条件 RL（VLaRL），它使冻结 VLA 的残差 RL 能够在仿真中训练，并部署到真实机器人上，而无需真实世界 RL 或在线自适应。关键挑战在于：尽管仿真与现实之间存在视觉差异，仍要迁移所学到的残差策略。VLaRL 不要求像素级的视觉对应，而是利用 VLA 内部的视觉-语言潜在表示来为残差控制提供条件，并将其作为 sim-to-real 迁移接口，同时学习一个轻量级映射器，将仿真得到的潜在表示变换到真实潜在分布。在四个接触密集的操作任务和两个 VLA 主干网络上，VLaRL 在所有任务-主干组合中都提升了真实世界成功率，而受控消融实验表明，潜在条件化和潜在对齐对于迁移仿真训练的残差控制都至关重要。

## Abstract
Vision-language-action (VLA) models provide broad, instruction-conditioned manipulation behaviors, but their physical execution can remain imprecise during contact-rich interaction. Residual reinforcement learning (RL) can correct such errors while keeping the VLA frozen, but real-robot RL is costly and safety-critical. We propose VLA Latent-Conditioned RL (VLaRL), which enables residual RL for frozen VLAs to be trained in simulation and deployed on real robots without real-world RL or online adaptation. The key challenge is transferring the learned residual policy despite the visual gap between simulation and reality. Rather than requiring pixel-level visual correspondence, VLaRL uses the VLA's internal vision-language latent representation to condition residual control and as the sim-to-real transfer interface, and learns a lightweight mapper that transforms simulation-derived latents toward the real latent distribution. Across four contact-rich manipulation tasks and two VLA backbones, VLaRL improves real-world success in all task-backbone combinations, while controlled ablations demonstrate the importance of both latent conditioning and latent alignment for transferring simulation-trained residual control.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **VLA 模型的优势与短板**：视觉-语言-动作（VLA）模型（如 RT-1/RT-2、OpenVLA、Octo、Flower、GR00T 等）已能在多样化操作任务中产生广泛、以语言指令为条件的行为。然而，真实世界的操作不仅需要“任务正确”，还需要“物理执行精确”。在接触密集的交互场景（如按钮按压、推物、堆叠、关抽屉）中，接触位置、对齐或持续接触的微小误差就可能导致任务失败。
- **核心矛盾**：VLA 可以生成合理的标称行为，但在局部物理执行上仍可能失败。若通过额外模仿学习来纠正，需要采集包含纠正动作的机器人演示并更新基础策略，成本高。
- **残差 RL 的适配性**：残差强化学习（Residual RL）保留预训练 VLA 作为先验，仅学习加性纠正动作，非常适合“冻结 VLA + 局部修正”的设定。
- **真实机器人 RL 的痛点**：在物理机器人上做 RL 需要大量重复交互，成本高、安全风险大。
- **本文目标**：让残差 RL **完全在仿真中训练**，并部署到真实机器人，**无需真实世界 RL 或在线自适应**。核心挑战在于仿真与现实的视觉差异（visual gap）会导致 VLM 潜在表示分布不一致。
- **整体含义**：VLaRL 提出以冻结 VLA 的内部视觉-语言潜在表示为残差控制条件与 sim-to-real 迁移接口，通过轻量映射器对齐仿真与真实潜在分布，从而把仿真学到的残差控制迁移到真机。

## 二、论文提出的方法论

### 2.1 核心思想

- 将冻结 VLA 视为两部分：
  - **视觉-语言模块**：`Z_t = E_VLM(o_t, ℓ)`，输出 token 矩阵 `Z_t ∈ R^{S×D}`。
  - **动作头**：`a^VLA_t ~ π_act(·|Z_t)`，产生标称动作。
- 残差策略以 VLM 的池化潜向量 `z_t ∈ R^D`、标称动作 `a^VLA_t`、本体状态 `s_t` 和腕部力 `f_t` 为输入，输出纠正动作：
  - `a^RL_t = π_RL(z_t, a^VLA_t, s_t, f_t)`
- 最终执行动作：`a_t = a^VLA_t + α·a^RL_t`，其中 `α` 为跨任务共享的固定残差缩放系数（文中为 0.10）。

### 2.2 四阶段流程

1. **Step 1：VLA 微调与数字孪生重建**
   - 采集真实机器人演示数据，微调 VLA 并冻结。
   - 用相同演示在 MuJoCo 中重建近似对应的任务配置（数字孪生），提供 sim–real 观测用于潜在映射与残差 RL 仿真环境。

2. **Step 2：Sim-to-Real VLM 潜在映射**
   - 学习映射器 `M_θ`，作用于池化前的模拟 token 矩阵：`Z̃^s_t = M_θ(Z^s_t)`。
   - 由于 sim–real 轨迹只是近似帧级对应，采用**最优传输（Optimal Transport）**做分布对齐。
   - 传输代价定义：`C_ij = ||M_θ(Z^s_i) − Z^r_j||²_F / (SD) + λ_τ(τ^s_i − τ^r_j)²`，其中 `τ` 为归一化轨迹进度，`λ_τ` 为权重。
   - 用**熵正则化最优传输**，通过 Sinkhorn 迭代求解传输计划。
   - 映射后的表示供冻结 VLA 动作头使用，并均值池化后供残差策略使用：`z̃^s_t = MeanPool(Z̃^s_t)`。
   - 映射器在残差 RL 阶段被冻结。
   - 映射器为四层 Transformer 编码器，16 个注意力头，前馈维度为 VLA token 维度的两倍；含可学习残差连接，缩放因子初始化为 0（初始近似恒等映射）。

3. **Step 3：仿真中训练残差 RL**
   - 使用 **TD3** 在仿真中训练残差策略。
   - 采用**非对称 actor–critic**：critic 额外接收仿真中的特权任务状态，actor 只用真实部署可获得的观测。
   - 引入**演示残差目标**作为辅助正则：`a^RL,demo_t = (a^demo_t − a^VLA_t) / α`。
   - VLA 与映射器全程冻结，只优化残差策略。

4. **Step 4：真实机器人部署**
   - 真实观测经冻结 VLA 得到 `Z^r_t`，均值池化得 `z^r_t = MeanPool(Z^r_t)`。
   - 残差策略直接使用真实 VLM 潜向量、标称动作、本体状态与力，**不使用映射器**，不进行任何真实世界 RL 或在线自适应。

## 六、论文的主要结论与发现

- **真实世界成功率全面提升**：VLaRL 在全部 8 个任务–骨干组合上均优于冻结 VLA 基线。
  - 显著提升案例：Flower 按钮按压 67.5% → 100.0%；Flower 方块推动 22.5% → 50.0%；GR00T N1.7 杯子堆叠 17.5% → 45.0%。
- **仿真中映射器的作用**：加入 Mapper 后，标称 VLA 在所有任务–骨干组合上的仿真成功率均提升，说明其减少了真实数据微调 VLA 在仿真观测上的表示偏移。
- **残差 RL 进一步提升仿真成功率**：例如 Flower 方块推动从 base 32.5% → Mapper 42.5% → VLaRL 67.5%。
- **消融结论**：
  - 去掉 Mapper：真实世界方块推动与杯子堆叠 **40 次全部失败**（0%），而完整 VLaRL 分别为 50.0% 与 70.0%，说明潜对齐对 sim-to-real 迁移至关重要。
  - 去掉 VLM latent：按钮按压 100.0% → 70.0%，方块推动 50.0% → 20.0%，说明 VLM 潜向量提供了标称动作、本体感觉与力之外的有用信息。
- **积分梯度归因分析**：
  - VLM 潜向量对残差动作范数的归因最大，Flower 为 72.1%–89.7%，GR00T N1.7 为 84.0%–90.9%。
  - 力的归因在方块推动（持续接触）中上升；本体感觉在杯子堆叠（精确位置调整）中相对更重要。
- **未见物体迁移**：
  - 方块推动真实成功率 40.0% → 57.5%；杯子堆叠 55.0% → 62.5%，且保留了冻结 VLA 的指令相关目标与角色选择能力。
- **仿真与真实趋势不完全一致**：说明潜对齐并未消除接触动力学、摩擦、柔顺性等物理差异。

## 七、优点

- **接口设计巧妙**：不要求像素级视觉对应，也不依赖显式物体位姿估计，而是复用冻结 VLA 内部的视觉-语言潜表示作为 sim-to-real 接口，兼顾紧凑性与语义/指令上下文。
- **完全仿真训练 + 零真机 RL**：残差策略仅在仿真中训练，部署时直接消费真实 VLM 潜向量，无需真实世界 RL 或在线自适应，显著降低安全风险与成本。
- **潜对齐机制**：用最优传输 + Sinkhorn 迭代训练轻量映射器，将仿真潜表示拉向真实分布，消融证明其不可替代。
- **非对称 actor–critic 与演示残差正则**：critic 用特权状态、actor 只用部署可得观测，配合演示残差目标，提升训练稳定性。
- **跨骨干验证**：在 Flower 与 GR00T N1.7 两种差异较大的 VLA 上均有效，说明方法具有架构通用性。
- **多维度分析**：除成功率外，还使用积分梯度分析各输入模态的贡献，增强可解释性。
- **保留 VLA 泛化性**：残差修正不破坏冻结 VLA 的指令条件行为，在未见物体上仍能保持目标与角色选择。

## 八、不足与局限

- **依赖数字孪生重建**：训练映射器需要近似对应的 sim–real 轨迹，需任务特定的数字孪生重建，扩展成本较高；减少或消除对配对数据的需求是未来方向。
- **未处理物理动力学差异**：映射器只对齐 VLM 表示分布，不显式处理接触动力学、摩擦、柔顺性等物理差异，这可能是仿真与真实趋势不一致的原因。
- **映射器与任务专用性**：
  - 映射器对每个 VLA 骨干是特定的。
  - 残差 RL 目前按任务类别单独训练，尚未实现跨骨干、跨技能的共享残差策略。
