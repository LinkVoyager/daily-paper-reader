## 摘要
视觉-语言-动作模型在机器人操作中取得了强大性能，但通常需要大量参数。在这项工作中，我们提出未来表征动作模型（Future Representation Action Model, FRAM），这是一种小型策略，显式地将未来末端执行器轨迹与当前视觉输入联系起来。FRAM 使用预测轨迹的图像坐标作为空间指针，从当前图像中读取与运动相关的局部视觉特征。这将用于动作生成的信息组织为参考位置（Where）、视觉状态（What）和未来运动（Future）。轨迹标签由演示和相机几何自动生成，因此无需人工标注。FRAM 具有 138.7M 参数，包括一个冻结的语言编码器，在四个标准 LIBERO 套件上达到 92.2% 的平均成功率，接近具有 3.3B 参数的 $π_0$ 的 94.2%。无需额外训练，它还在 LIBERO-Plus 上达到平均 67.3%。消融实验证实，未来轨迹和局部视觉特征都能提升性能和鲁棒性。在真实双臂 UR5e 上，FRAM 仅使用腕部相机即可堆叠杯子，包括选择和切换左臂与右臂。这些结果表明，基于未来运动选择视觉信息是在小型机器人策略中同时获得高性能和鲁棒性的有效方法。

## Abstract
Vision-Language-Action models achieve strong performance in robot manipulation, but often require large numbers of parameters. In this work, we propose the Future Representation Action Model (FRAM), a small policy that explicitly links the future end-effector trajectory to the current visual input. FRAM uses the image coordinates of the predicted trajectory as spatial pointers and reads local visual features related to the motion from the current image. This organizes the information for action generation into the reference position (Where), the visual state (What), and the future motion (Future). Trajectory labels are generated automatically from demonstrations and camera geometry, so no manual annotation is needed. With 138.7M parameters, including a frozen language encoder, FRAM reaches an average success rate of 92.2% over the four standard LIBERO suites, close to the 94.2% of $π_0$ with 3.3B parameters. Without extra training, it also reaches an average of 67.3% on LIBERO-Plus. Ablations confirm that both the future trajectory and the local visual features improve performance and robustness. On a real dual-arm UR5e, FRAM stacks cups using only wrist cameras, including choosing and switching between the left and right arms. These results show that selecting visual information based on future motion is an effective way to obtain both high performance and robustness in a small robot policy.

## 1. 核心问题与研究背景

- **背景**：机器人正从结构化工厂环境走向维护、服务等多样化场景，要求策略能在物体、布局、语言指令变化时仍产生正确动作。Vision-Language-Action（VLA）模型（如 OpenVLA、π₀）通过大规模多源数据学习视觉—语言—动作映射，取得了强性能。
- **核心痛点**：主流 VLA 动辄数十亿参数，其微调与推理需要大量算力，难以部署到算力受限的现场设备。
- **关键洞察**：小型模型若要表现良好，不能只靠“缩小模型”，还必须在**信息表示层面**做文章——即从整幅图像中主动**筛选与即将执行动作相关的视觉信息**，并以有限容量可用的形式组织。
- **现有工作的不足**：
  - 空间注意力类方法只用图像坐标作为低维中间表示，丢失了物体外观与周围环境信息，也无法显式表达未来运动路径。
  - 轨迹类方法（ATM、MT-π、RT-Trajectory）把轨迹用作运动预测、动作表示或外部指令，但**没有沿预测轨迹从当前图像中显式读取所需视觉信息**，未来路径与沿途物体/环境的关系只能隐式学习。
  - 未来状态类方法（CoT-VLA、ThinkAct）生成未来子目标图像或视觉潜规划，同样未显式指明轨迹对应当前图像中的哪个区域。
- **整体含义**：本文主张“基于未来运动选择视觉信息”是小型机器人策略同时获得高性能与鲁棒性的有效途径，并将信息组织为三个明确角色：参考位置（Where）、当前视觉状态（What）、未来运动（Future）。

## 2. 方法论：FRAM（Future Representation Action Model）

### 2.1 核心思想
- 受人类“手未动、眼先看目标”的眼手协调现象启发：先预测未来末端执行器轨迹，再**用轨迹的图像坐标作为空间指针**，从当前图像特征图中读取局部视觉特征。
- 轨迹既是动作生成的条件，也是**几何上与未来运动绑定的注意力位置**，从而抑制背景或无关物体变化对条件的干扰。

### 2.2 关键技术流程

**（1）输入与编码器**
- 观测 = 语言指令 ℓ + 末端状态 sₜ（3D 位置 + 6D 连续旋转 + 夹爪开度，共 10 维）+ 外部相机图像 Iᵃₜ + 腕部相机图像 Iʷₜ。
- 语言：冻结的 SigLIP 文本编码器，输出 token 序列 L_ℓ 与句嵌入 e_ℓ。
- 视觉：ImageNet 预训练 ResNet-18 的第三残差阶段，两视图共享权重；经 1×1 卷积降维后，用 e_ℓ 生成的 γ、β 做 FiLM 调制：
  - Fᵛₜ = (1 + γ(e_ℓ)) ⊙ φ(Iᵛₜ) + β(e_ℓ)
  - 同一图像在不同指令下被强调的区域会随之改变。
- 全局观测特征 gₜ：两视图全局视觉特征 + 状态嵌入 + 语言嵌入拼接后过 MLP。

**（2）未来轨迹预测与标签自动生成**
- 每个视图一个 Transformer 解码器：K 个可学习 query 对“图像 token + 语言 token + 末端状态 token”构成的 memory 做交叉注意力，直接回归第 k 个点：
  - ẑᵛₜ,ₖ = [q̂ᵀ, d̂, ôᵀ]ᵀ，其中 q̂ 为归一化图像坐标，d̂ 为相机系深度，ô ∈ R⁶ 为将末端三个轴投影到图像得到的朝向偏移。
- **标签生成（无需人工标注）**：
  - 按夹爪指令切换时刻把演示切分为子任务（approach/grasp/transport/release 等）；
  - 预测区间终点 e(t) = max(当前子任务终点, t + H)，并在演示末尾截断，保证子任务末尾前区间不小于 H；
  - 在基座标系对 [t, e(t)] 内末端位置拟合分段三次 B 样条，以当前位姿、区间终点、区间内夹爪切换点为精确经过的节点，按**等弧长**采样 K 点（消除速度差异，只表达路径几何）；
  - 用当前时刻相机外参 ᵛT_b(t) 与内参 Kᵥ 投影：qᵛₜ,ₖ = Π(Kᵥ · ᵛp(t)ₖ)，Π([x,y,z]ᵀ)=[x/z, y/z]ᵀ；
  - 腕部相机的外参由当前末端位姿与手眼变换算出，**因此不需要未来相机位姿**，预测坐标可直接作为当前图像特征图上的参考位置；
  - 朝向标签由末端原点及三轴端点投影后取图像空间差值拼接成 6D。
- **越界与无效点处理**：投影到图像外的点保留 [-1,1] 之外的真实坐标作为标签（保留“运动将离开视野”的信息）；相机后方（z ≤ 0）与远离光轴（1/z 发散）的点从损失中剔除。

**（3）轨迹引导的局部特征提取**
- 将预测点 q̂ᵛₜ,ₖ 映射到 Fᵛₜ 的网格坐标，以该点为中心采样 3×3 邻域，用**可微 grid sample** 双线性插值后取均匀平均得到 hᵛₜ,ₖ；图像外坐标裁剪到特征图边缘。
- 三种特征：
  - fᵛ_traj = (1/K) Σ hᵛₜ,ₖ：路径沿途的视觉状态（抓取物与沿途物体）；
  - fᵛ_target = hᵛₜ,K−1：目标位置（待抓物或放置点）的视觉状态；
  - fᵛ_attn：以 fᵛ_target 为 query、Fᵛₜ 全部 token 为 key/value 的单层注意力，用于预测端点略有偏差时补全相似区域特征。
- fᵛ_local = MLP([fᵛ_traj; fᵛ_target; fᵛ_attn])，逐视图独立计算。**What 不是预测未来图像，而是由未来运动选出的当前图像视觉状态。**

**（4）动作专家与流匹配生成**
- 条件向量 cₜ = 全局特征 gₜ + 各视图轨迹嵌入（展平后过 MLP）+ 各视图 fᵛ_local。
- 每个预测点再经线性投影 + 可学习位置嵌入变成**轨迹 token**，作为动作生成器的交叉注意力 memory，使动作块每一步可直接参考轨迹点的位置、深度、朝向。
- 流匹配：动作块 A₁ ∈ R^{H×d_a}，每步含末端增量平移/旋转与夹爪命令（夹爪按 ±1 连续值生成，执行时取符号决定开合）；训练时 A_τ = (1−τ)A₀ + τA₁，A₀ ~ N(0,I)，τ ~ U(0,1)。
- 速度场 v_θ 把动作块每步视作带时间位置嵌入的 token，每块依次做：(i) 由 cₜ、τ 嵌入、语言嵌入做 FiLM 条件的残差 MLP；(ii) 步间自注意力 + 对轨迹 token 交叉注意力的 Transformer 层。
- 损失：L_FM = E[‖v_θ(A_τ, τ, cₜ, e_ℓ, Ẑₜ) − (A₁ − A₀)‖²_valid]，范数仅在有效元素（排除演示结束后的 padding）上取均方误差。
