## 摘要
任务规划在长时程操作中连接高层指令与可执行行为，然而现代视觉-语言-动作（VLA）系统往往将这一中间结构隐式化。现有的思维链（CoT）规划器也倾向于依赖粗粒度的任务级标注，或逐 token 序列化冗长的推理轨迹。我们提出 X-Planner，一个规划前端，同时处理具身推理的监督与表示问题。我们的规划数据在层次化粒度下融合了 Ego、UMI 和遥操作数据，并具有随数据来源而异的标注深度。接管时刻标注和人工设计的失败用于监督进行中的错误识别。在模型侧，一个共享的 VLM 主干提供两种事件结构化的规划形式：一种离散接口，输出可解释的事件状态；一种潜在接口，通过 Staircase Decoding 在交错的 Transformer 深度间传递连续的 CoT 状态。一个冻结的潜在到文本重建目标为潜在表示提供语义锚点。离线两步规划评估中，X-Planner 在四个被评估模型上于 BERTScore-F1 和基于评判的 Overall 分数上均位列第二。在真实机器人实验中，相应地优于所评估的基线。这些结果刻画了规划文本质量和下游执行表现。

## Abstract
Task planning bridges high-level instructions and executable behavior in long-horizon manipulation, yet modern Vision-Language-Action (VLA) systems often leave this intermediate structure implicit. Existing chain-of-thought (CoT) planners also tend to rely on coarse task-level annotations or serialize long reasoning traces token by token. We present X-Planner, a planning front-end that addresses both the supervision and representation of embodied reasoning. Our planning data combine Ego, UMI, and teleoperation under a hierarchy granularity with source-dependent annotation depth. Takeover-time annotations and human-designed failures supervise ongoing error recognition. On the model side, a shared VLM backbone exposes two event-structured plan forms: a discrete interface that emits interpretable event states and a latent interface that relays continuous CoT states across staggered Transformer depths through Staircase Decoding. A frozen latent-to-text reconstruction objective provides a semantic anchor for the latent representation. Offline two-step planning evaluation places X-Planner second among four evaluated models on both BERTScore-F1 and a judge-based Overall score. In real-robot experiments, respectively, outperforming the evaluated baselines. These results characterize planning-text quality and downstream execution.

- **背景**：具身基础模型通过将视觉观测与自然语言指令直接映射为可执行动作，在短时程、定义明确的技能上表现良好；但长时程操作需要智能体先选择并排序有依据的子目标，再发出底层指令。
- **核心问题**：现代 VLA（视觉–语言–动作）系统普遍将"高层意图→底层控制"之间的任务规划中间结构**隐式化**，缺乏显式表示。近期引入思维链（CoT）推理的系统虽有所改进，但具身任务规划仍在数据构建、规划粒度、解码策略三方面割裂。
- **三个具体缺口**：
  - **数据缺口**：现有规划器多用任务级描述或固定任务套件的手写子目标列表训练，标注很少指明一个子目标在哪里结束、下一个在哪里开始；单条 episode 描述会掩盖重抓取、失败接触、重试、小幅位姿修正等内部事件结构。且单一策略采集的失败样本会过度代表该策略的特征性错误。
  - **粒度缺口**：推理型规划器往往采用单一、外部强加的粒度——有的在固定语义层级输出文本，有的预测子目标图像或光流；固定长度分块可能切裂一个行为或合并多个行为。
  - **延迟缺口**：传统 CoT 规划器逐 token 自回归解码推理，长 rollout 中反复处理重叠的视觉–语言上下文，延迟下一次规划交接；长显式轨迹也易受错误传播影响。潜空间 CoT 方法虽用连续状态替代离散 token，但许多仍保留潜步骤间的串行依赖。
- **整体含义**：论文提出 X-Planner，一个任务规划前端，同时解决上述三个缺口，输出**事件结构化表示**以条件化下游世界–动作模型，并围绕"动作对齐的语义事件、可复现监督、显式与潜空间互补接口"重新框定具身规划。

## 2. 方法论

### 2.1 核心思想

- 采用**语义事件**作为规划单元：一段时间上连贯的可执行行为（如伸手、抓取、抬起、放置），其边界跟随行为变化。相比固定长度 chunk，事件在语言上可理解、在视频中可观测、可通过控制实现，是合适的中间层。
- 给定高层指令 ℓ、当前多视角观测 {V(v)₀}ᵥ 和可选历史 h，输出事件结构化表示以条件化下游世界–动作模型。
- 共享 Qwen 系列 VLM 主干提供视觉–语言特征，用于场景 grounding、事件分解与进度估计。

### 2.2 两种规划形式

- **离散形式（结构化事件状态）**：
  - 执行开始时输出有序初始计划；rollout 中结构化响应涵盖归一化进度、当前事件、下一事件（若可用）、延续状态、执行错误识别；在最后一个可用媒体帧发出 episode-end 标记。
  - 事件描述形如"align the gripper above the red cup"，可被人类或上游智能体检查与编辑，并作为下游世界–动作模型的文本接口。
  - episode-end 标记仅表示录制媒体边界，本身不是语义任务成功的证明。
- **潜空间形式（并行连续 CoT）**：
  - 将计划表示为 K_c 个连续推理状态 ŷ₁:ₖ_c，由 staircase 分支并行生成并直接注入下游 cross-attention 通路。
  - 两种形式共享 VLM 主干与事件 grounded 语义，区别仅在于计划以文本暴露还是保留为连续状态。

### 2.3 文本条件接口

- 用边界掩码 m_txt 选出文本 token 的 VLM 隐藏状态 H_q，经可学习投影 P_Q 后进入下游原生文本 MLP M_T，得到条件序列 c_ℓ = M_T(P_Q(H_q[m_txt]))，与图像 token 一同进入世界–动作 cross-attention 层。
- 该接口允许规划器加入场景 grounded 消歧、任务分解、进度感知事件上下文，而不替换下游文本通路。

### 2.4 Staircase Decoding（潜空间 CoT）

- 传统自回归潜 rollout 中每个推理状态依赖前一状态并遍历完整 Transformer 栈；Staircase Decoding 通过**深度并行调度**缩短串行路径。
- 推理分支由微调后的 VLM 初始化，实现为与冻结主干耦合的轻量 Mixture-of-Transformers（MoT）结构。
- 在 relay depth N_r 处切分 Transformer：下层编码共享视觉–语言上下文，上层跨推理步骤专门化。第一个潜位置遍历下层产生被所有推理位置共享的 relay 表示；上层块随后并行更新潜状态，每个位置有独立因果缓存。
- 公式表示为 ŷ₁:ₖ_c = F_stair(x; N_r)，其中 x = ({V(v)₀}ᵥ, ℓ, h)，N_r 控制推理路径分叉前共享多少 grounding 计算。
- 相对全自回归 rollout，该调度跨推理状态复用下层视觉–语言特征，结果潜变量条件化下游 cross-attention 而无需离散 token 采样。
- 论文明确指出：该架构性串行计算缩减本身并不确立端到端控制延迟更低，后者还依赖周边执行栈。

### 2.5 冻结潜文本重建

- 目的：让紧凑潜状态保留预期事件语义，而非匹配某条特定的自回归隐藏状态序列。
- 前缀投影器 P_pref 将 ŷ₁:ₖ_c 映射为冻结轻量语言模型嵌入空间中的软前缀 z₁:ₖ_c；语言模型在该前缀条件下自回归重建对应文本 CoT 轨迹：P_φ(r₁:ₘ_r | z₁:ₖ_c)，损失 L_CoT 为负对数似然之和。
- 只优化 staircase 推理分支与 P_pref，重建模型保持冻结。重建轨迹鼓励潜序列保留高层语义而不复制特定 token 级隐藏轨迹；冻结解码器还可将潜计划渲染为文本以供定性检查。

### 2.6 推理与部署

- **event mode**：X-Planner 启动时输出初始计划，随新观测更新结构化事件状态；事件描述条件化世界–动作模型，进行中的错误识别支持执行监控；由执行系统决定何时刷新或提交状态。
- **unified mode**：staircase 解码器产生 K_c 个连续 CoT 状态，通过同一 cross-attention 接口条件化固定长度动作 chunk 推理。

### 2.7 训练目标

- **结构化计划状态监督（L_SFT）**：数据管道物化三类事件状态（初始计划 / 执行中 / episode 结束）；对全部 assistant token 自回归监督，而非只优化下一事件 caption 或把进度作为独立标量回归；caption、进度、延续状态、标注错误在结构化响应中联合学习。缺失标注层级不贡献监督（如 Ego/UMI 无 L0 不视为负 Segment 标签）。
- **文本条件特征对齐（L_align）**：对齐规划器侧条件路径与下游模型原始文本特征空间，鼓励规划器表示保持在下游固定接口期望的几何中；是模型侧损失，不是替代 assistant 目标。
- **Staircase 蒸馏（L_CoT）**：初始化分支自预训练 VLM 权重，迁移主干视觉–语言表示到并行潜 rollout；目标 r₁:ₘ_r 为标注推导的轨迹，与离散形式共享事件语义。该阶段与 compact-JSON SFT 不同：共享主干与语义 grounding，但目标与读出不同。
- 论文明确：三项目标角色分开报告，因为当前系统级实验**未隔离各自的因果贡献**；下游世界–动作模型全程固定。

## 3. 实验设计

### 3.1 数据与场景

- **规划数据来源**：Ego（第一视角）、UMI、遥操作三类演示，共享 L3 Task / L2 Subtask / L1 Action / L0 Segment 层级。遥操作携带全部四级；Ego 与 UMI 因运动更快、L0 边界难以可靠标注，仅保留 L1–L3。数据经同步与筛查（缺失观测、时间戳不一致、不可用记录）。
- **失败感知进行中监督**：在干预 episode 中标注接管时刻，提供执行中错误识别的时间监督；并用人类执行的刻意设计失败模式补充，以扩大错误覆盖、降低对单一策略失败分布的依赖。

- **真机 Reasoning Manipulation**：X-Planner-conditioned 策略取得最高平均 Task Progress 71.60，U-Scratch 59.50、π0.5 56.40、DreamZero 32.70、LingBot-VA 31.60；比最强报告基线 U-Scratch 高 12.10 个百分点。任务级上，X-Planner 在有序按钮按压与指令条件水果选择上更强，与 U-Scratch 在耳机分拣上四舍五入同分；U-Scratch 在形状分类更高，π0.5 在物品配对最好。
- **真机 Generalization**：X-Planner 平均 53.75，DreamZero 28.50、π0.5 24.00、U-Scratch 18.50；比最强可用基线 DreamZero 高 25.25 个百分点。LingBot-VA 在该设置无结果，标记 N/A。
- **总体结论**：事件 grounded 规划可作为高层指令与动作生成之间的有用接口；两个层面的评测分别刻画规划文本质量与下游执行。同时论文承认与 kimi3 在离线文本比较上仍有可测量的差距。

## 7. 优点

- **以语义事件作为规划单元**：兼顾语言可理解性、视频可观测性与控制可实现性，避免固定长度 chunk 切裂/合并行为的粒度问题，是较有说服力的中间表示设计。
- **多源分层监督与来源相关标注深度**：Ego/UMI/遥操作共享 L3–L0 层级，按来源可靠地确定标注深度（Ego/UMI 止于 L1，遥操作到 L0），并显式说明缺失层级不作为负标签，标注设计务实。
- **失败感知的进行中监督**：利用接管时刻标注 + 人工设计失败样本，既监督错误识别又缓解单一策略失败分布偏置，是相对现有工作的一个具体改进点。
-

- **显式与潜空间双接口共享同一事件语义**：两种规划形式共用 VLM 主干、事件 grounded 语义与下游 cross-attention 入口，使得"文本暴露 vs 连续状态保留"成为一个可切换的接口选择，而非两套互不相干的系统；这种设计为后续受控比较预留了干净的结构前提。
- **Staircase Decoding 的调度思路有针对性**：把"跨推理状态可复用的视觉–语言 grounding 计算"下沉到共享下层、把"步骤专有化"上移到并行上层，直接回应了自回归潜 rollout 串行路径过长的结构性问题，且用 relay depth N_r 提供一个可解释的共享/专精权衡旋钮。
- **冻结潜文本重建的正则化取向明确**：以冻结轻量语言模型重建文本 CoT 作为监督，目标是让潜状态保留高层事件语义而非复刻某条 token 级隐藏轨迹，避免了潜空间表示退化为对特定解码路径的记忆，同时免费获得"潜计划可渲染为文本"的定性检查能力。
- **表述上的自我克制**：论文主动声明 staircase 的串行计算缩减不等于端到端控制延迟更低、episode-end 标记不等于任务成功、下游世界–动作模型全程固定、三项训练目标未做因果隔离。这种边界声明在具身规划类工作中并不常见，提高了结论的可解释性。
- **覆盖分析具备可审计性**：以确定性规则从 1654 个候选中保留 1500 个、显式说明去除 154 个冗余高频组合的理由，并报告长尾（167 个数据集、30 个任务类别、unknown 标签）与中位数/P90 等分布统计，使数据选择效应可被复核。

## 8. 局限与不足

- **组件贡献未被隔离**：错误监督数据、离散事件状态表示、潜空间形式、staircase 调度、L_SFT/L_align/L_CoT 三者均无单变量消融；真机结果只能归因于"event-mode 整体系统"，无法回答"哪一个设计真正起作用"。
- **两种规划形式缺乏受控对比**：论文将 event mode 与 unified mode 的直接比较列为未来工作，意味着"显式文本接口 vs 并行潜接口"这一核心架构主张目前没有实证支撑，仅有设计论证。
- **无延迟证据**：尽管方法论围绕"延迟缺口"展开，离线与真机评测均未报告端到端延迟或规划交接时延，staircase 的实际效率收益仍是架构层面的推断。
- **统计严谨性薄弱**：无 trial 级分数、无方差或置信区间、图 5 有意省略误差棒，离线结果亦未做显著性检验；因此 12.10 与 25.25 个百分点的领先幅度只能读作报告均值之差，不能读作稳定优势。
- **离线文本并非最优**：在 BERTScore-F1 与 Overall 两项上均落后 kimi3，说明其事件结构化监督并未在纯文本规划质量上取得全面领先，论文对此差距的成因未做分析。
- **指标与目标之间存在落差**：BERTScore-F1 衡量语义相似度而非任务成功率，Overall 依赖 Doubao Judge 的综合评分，两者都可能与"规划是否真正可执行"脱钩；而 Task Progress 虽为密集分，却由任务特定 rubric 给出，跨任务可比性受限。
- **评测规模与精度有限**：Reasoning Manipulation 仅 5 个任务、Generalization 仅 1 个场景套件，任务级数值来自四舍五入的图表读数，suite 级为分别报告的均值，难以支撑细粒度结论。
- **平台单一**：真机仅桌面双臂机器人一种形态，事件边界、进度估计与错误识别能否迁移到移动操作、多机协作或长时程（最长 822.7 s 的 episode 已接近上限）尚未验证。
- **数据分布偏斜**：刚性物体 58.2%、pick-and-place 85.8%、Move/Grasp/Place 三类原子动作主导，长尾标签虽被保留但样本量小，模型在柔性物体、精细装配等场景的规划能力存在系统性不确定。
- **事件边界与标注一致性依赖人工协议**：L0 仅在遥操作数据中可用，Ego/UMI 因运动过快而缺失，事件切分的可靠性在不同来源间并不均等；失败样本还混入人工设计的刻意失败，其与真实失败分布的比例未报告。
- **L_align 的几何约束存在潜在张力**：将规划器条件表示对齐到下游固定文本特征空间，可能限制规划器表达超出下游接口预期的语义；论文未讨论这种对齐是否带来信息瓶颈。

## 9. 对领域的影响与可复现性

- **概念贡献**：把"语义事件"确立为高层意图与底层控制之间的显式中间层，并主张规划单元应同时满足语言可理解、视频可观测、控制可实现三条约束，为具身规划的粒度问题提供了一个可复用的判据。
- **工程贡献**：分层多源标注（L3–L0）、按来源决定标注深度、失败感知的进行中监督、以及"缺失层级不视为负标签"的处理方式，对后续构建规划数据集具有直接借鉴价值。
- **架构贡献**：Staircase Decoding 与冻结潜文本重建的组合，展示了一条"共享 grounding、并行推理、语义正则"的潜空间 CoT 路线，可作为潜推理规划器的一个设计模板。
- **可复现性评估**：算力、参数量、训练时长、超参数、数据划分细节与 trial 级结果均未披露，真机协议虽声称匹配（任务定义、指令、观测、随机化、评分规则），但缺少可复现所需的完整规格；当前状态下更接近"方法论与方向性证据"，而非可直接复刻的系统报告。

## 10. 总体评价

X-Planner 的定位是**任务规划前端**，其价值主要在于问题框定与表示设计：它把具身规划的痛点拆解为数据、粒度、延迟三个缺口，并给出一个以语义事件为轴、显式文本与并行潜状态双接口、由多源分层监督与冻结潜文本重建支撑的统一方案。实验在两个层面（规划文本质量、下游执行）都给出了正向信号，真机 Task Progress 上相对最强基线的领先幅度也具备实践吸引力。

但就其自身提出的三个缺口而言，证据强度并不对称：**粒度缺口**得到了表示层面的充分论证，**数据缺口**通过标注协议与覆盖分析得到部分回应，而**延迟缺口**在实验上完全没有被测量。加之缺少消融、受控对比与统计检验，论文目前更适合被读作一份设计合理、边界声明诚实的系统提案，而非对三个缺口同时给出确证解的实证研究。后续工作最关键的补足项依次是：两种规划形式的受控比较、三项训练目标的单变量消融、以及端到端延迟与 trial 级统计的实测报告。
