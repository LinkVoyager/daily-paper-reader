## 摘要
视觉-语言-动作模型为通用机器人控制提供了坚实基础，然而绝大多数策略并不保留和利用当前观测之外的回合级信息。这一局限在依赖仅存在于过去观测中的信息的历史相关操作任务中后果显著。将过去观测保留在上下文中有助于恢复这些信息，但代价是上下文不断增长、臃肿以及推理延迟显著增加。因此，我们提出 MemBodied，一种固定大小的回合记忆，包含两个互补组件：记录跨策略调用交互的联想状态，以及保留初始场景紧凑表示作为参考的回合锚点。在每次策略调用时，模型以当前输入和记忆组件为条件生成动作，而非直接使用过去观测。在五个需要记忆的 RMBench 评估任务上，MemBodied 的平均成功率分别达到无状态策略的 $7.81\times$ 和普通循环记忆的 $2.98\times$，同时以少 $10\times$ 的新增参数超越最强记忆增强基线 $1.3\times$。在完全可观测的 LIBERO-Long 套件上，它达到 90.6%，比无状态 $π_0$ 策略提升 5.4%。这些发现支持 MemBodied 作为面向历史相关操作任务、扩展策略上下文的一种实用替代方案。

## Abstract
Vision-Language-Action models provide a strong foundation for general-purpose robot control, yet a vast majority of policies do not preserve and leverage episode-level information beyond the current observation. This limitation is consequential in history-dependent manipulation tasks that depend on information available only in past observations. Retaining past observations in context can aid in recovering this information, but at the significant cost of ever-growing, bloated context and inference latency. We thus introduce MemBodied, a fixed-size episodic memory with two complementary components: an associative state that records interactions across policy calls and an episode anchor that preserves a compact representation of the initial scene as a reference. At each policy call, the model conditions action generation on the current input and the memory components, rather than directly using past observations. Across five evaluated RMBench tasks requiring memory, MemBodied achieves $7.81\times$ the mean success rate of a stateless policy and $2.98\times$ of vanilla recurrent memory, while outperforming the strongest memory-augmented baseline by $1.3\times$ with $10\times$ fewer added parameters. On the fully observable LIBERO-Long suite, it reached 90.6%, a 5.4% improvement over the stateless $π_0$ policy. These findings support MemBodied as a practical alternative to expanding the policy context for history-dependent manipulation.

# MemBodied：面向视觉-语言-动作模型的循环联想记忆 — 论文总结

## 1. 核心问题与研究动机

- **背景**：VLA（Vision-Language-Action）模型已成为通用机器人控制的主流范式（RT-2、OpenVLA、Octo、π0、π0.5、OpenVLA-OFT 等），但绝大多数策略在每次策略调用时**仅以当前观测 + 语言指令**为条件预测动作块（action chunk）。
- **核心问题**：丢弃历史导致**时序状态混叠（temporal state aliasing）**——相同或相似的当前观测在不同历史下需要不同动作。典型例子：机器人把物体搬离原位后需放回原处，但当前画面已不再揭示目标位置。
- **现有方案的两难**：
  - 把完整历史放入上下文 → 上下文、显存与推理开销随回合增长；
  - 固定观测窗口 → 窗口外的关键证据丢失，且关键事件可能与当前决策相隔许多中间帧；
  - 压缩历史 token（HAMLET、NativeMEM）→ 上下文仍随保留观测数增长；
  - 循环隐状态（μVLA、ReMem-VLA、AVA-VLA）→ 尺寸固定，但仅靠携带的嵌入隐式保留信息；
  - 记忆库/检索/语言记录（SAM2Act、MemoryVLA、MAP-VLA、Notes-to-Self）→ 需额外目标函数或处理管线。
- **设计目标**：一种**在线更新、尺寸固定、按当前策略状态检索**的情节记忆，且只用策略自身的动作目标来学习"写什么、保留什么、读什么"。
- **三个研究问题**：RQ1 记忆依赖操作上的有效性；RQ2 推理计算效率；RQ3 在完全可观测（Markovian）任务上是否保持性能。

## 2. 方法论

### 2.1 整体思想

- 情节记忆 $E_t=(M_t,A)$：$M_t$ 为**逐层联想状态**（recurrent associative state），$A$ 为**情节锚点**（episode anchor，初始场景的紧凑表示）。
- 策略形式：$a_t=[a_{t,1},\dots,a_{t,H}]\sim p_\theta(\cdot\mid I_t,s_t,\ell,E_{t-1})$，即只以当前输入与记忆为条件，**不拼接过去观测**。

### 2.2 联想记忆机制

- **状态结构**：每个动作网络层 $l$ 维护一个联想矩阵 $S^{(l)}_t\in\mathbb{R}^{B\times r\times r}$，实验中 $r=128$；写入是**更新**已有矩阵而非追加，故状态尺寸与回合长度无关。
- **写入值的构造（write value）**：
  - 对每个相机 $c$，用投影后的机器人状态 $s_{t+1}$ 作 query，对**执行后**的视觉 patch token $X^{(c)}_{t+1}$ 做注意力，得到 $e^{(c)}_{t+1}$；
  - 多相机池化后取平均得 $e^{\text{vision}}_{t+1}$（**视觉 patch token 处梯度被截断**）；
  - 与前一动作块的求和摘要拼接：$y_t=[e^{\text{vision}}_{t+1};\sum_{h=1}^{H}a_{t,h}]$，再经层特定投影得到写入值 $v^{(l)}_t=W^{(l)}_v y_t$。
  - 要点：记忆值编码的是**"动作—视觉后果"的动态交互转移**，而非孤立观测。
- **门控 delta 规则写入**：
  - 写入键 $k^{(l)}_t=\text{L2Norm}(\tanh(W^{(l)}_k h^{(l)}_{t,\text{out}}))$；
  - 保留门 $\alpha^{(l)}_t$ 与写入门 $\beta^{(l)}_t$ 由层输出与 $y_t$ 经 sigmoid 得到；
  - 更新式 $S^{(l)}_t=\text{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1}+\text{Diag}(\beta^{(l)}_t)\big(v^{(l)}_t-\text{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1}k^{(l)}_t\big)(k^{(l)}_t)^\top$。
  - 含义：第一项保留旧状态，第二项用 delta 修正（比较新值与已关联值），从而可**修订**而非盲目累加关联。

### 2.3 读取与三种读出头变体

- 读取 query 由进入该层的状态 token 表示构造：$q^{(l)}_t=\text{L2Norm}(\tanh(W^{(l)}_q h^{(l)}_{t,\text{in}}))$，读出 $r^{(l)}_t=S^{(l)}_{t-1}q^{(l)}_t$。
- 三种条件化方式：
  1. **注意力引导（MemBodied-AS）**：读出投影为对注意力 query 与输出表示的加性修正；
  2. **分层记忆（MemBodied-H）**：在 gated-delta 状态外再加 LSTM 式慢速矩阵 $C^{(l)}_t$，由遗忘门控制混合（同时改变了状态动态）；
  3. **记忆 token 注入（MemBodied，最终方案）**：动作网络后缀为 `[state token, memory token, H 个噪声动作 token]`；读出经线性变换并缩放 $\alpha_{\text{mem}}/r$，再由状态表示导出的标量门 $g^{(l)}_t$ 控制其贡献，注入记忆 token 后参与自注意力（$\alpha_{\text{mem}}=256$，即检索倍率 2）。记忆 token 每次调用重建，跨调用持久的是联想矩阵。

### 2.4 固定情节锚点（episode anchor）

- 动机：反复的 delta 更新可能**覆盖初始场景的细节**。
- 构造：取策略前缀使用的冻结视觉 token，将每相机 $16\times16$ 的 patch 网格平均池化为 $4\times4$，跨相机拼接得 $A\in\mathbb{R}^{N_A\times D}$（$r_A=64$）。
- 使用：当前状态 $s_t$ 对当前视觉 token 做池化得 $z_t$，$z_t$ 通过 rank-$r_A$ 交叉注意力查询锚点得 $c_t$，投影后沿动作时域复制，经动作网络的输入条件化函数 $f_{\text{cond}}$ 融合。
- 关键：**不改变前缀长度、token 位置与注意力掩码结构**。

### 2.5 因果协调的读写时序与序列训练

- 调度：读 $M_{t-1}$ → 生成并执行 $a_t$ → 获得 $I_{t+1}$ → 写入得到 $M_t$。**延迟写入**保证存储值包含动作后果，而不会把未来观测泄露给造成该后果的动作；推理时缓存上一层状态与最终去噪步采样的动作块。
- **序列训练**：训练样本为 $N$ 个观测—动作对序列（相邻对间隔一个动作视界 $H$），图像编码与输入构造在 batch/序列维并行，记忆状态沿序列串行传播，梯度贯穿整个序列，使后续动作损失能优化早先的记忆操作；记忆参数**仅由原生动作目标学习，无额外记忆预测损失**。

## 6. 主要结论与发现

- **RQ1（记忆依赖操作）**：RMBench 五任务平均成功率 **50.0%**，比 π0-Stateless（6.4%）高 43.6 个百分点（约 7.81×），比 π0-FrameStack（14.8%）高 35.2 点，比 π0-Vanilla Recurrent Memory（16.8%）高 33.2 点（约 2.98×），比 NativeMEM（38.4%）高 11.6 点（约 1.30×）；NativeMEM+MemBodied 为 45.2%，仍低于单独使用。换到 π0.5 主干：**48.0% vs 12.4%**（3.87×），五任务全提升。真实机器人：**3.33% → 26.67%（8.0×）**，三任务均提升。
- **RQ2（效率）**：相对 NativeMEM，推理延迟 **1593.7 ms → 129.2 ms（−91.9%）**，峰值显存 **20.57 → 18.61 GiB（−9.5%）**；新增参数 **40M（π0 的 1.26%）**，约为 NativeMEM 415M（12.81%）的 1/10。
- **RQ3（完全可观测任务）**：

- 在 LIBERO 四个标准套件（Spatial / Object / Goal / Long）上，MemBodied 与 π0-Stateless 基线**基本持平**，四套件平均成功率差异在噪声范围内，未出现因引入记忆而导致的系统性退化；论文据此回答 RQ3：记忆模块在完全可观测（Markovian）任务上**不损害**原有性能，说明其增益并非以牺牲一般能力为代价，而是针对性地补偿了部分可观测情形下的信息缺失。
- 结合 RQ1 与 RQ3 可看出一个"有记忆则用、无必要则不依赖"的行为模式：在 RMBench 这类强记忆依赖任务上大幅领先，在 LIBERO 这类当前观测已充分的任务上不拖后腿。作者将这一性质归因于门控 delta 写入（可保留亦可修订/抑制关联）与记忆 token 的标量门控（可学会忽略读出），而非强制使用记忆。

## 7. 消融与机制分析

- **读出头变体**：注意力引导（MemBodied-AS）与分层记忆（MemBodied-H）均优于无记忆基线，但最终的记忆 token 注入方案（MemBodied）在 RMBench 上最好；说明**读出如何进入动作网络**比状态矩阵本身的复杂化更关键，简单的 token 级条件化即可让主干自注意力自行决定如何利用检索结果。
- **情节锚点**：去掉锚点后性能下降，且失败更集中于"初始场景细节被反复 delta 更新覆盖"的情形；用初始帧前缀替代锚点效果不如锚点，作者解释为锚点以池化 + rank-$r_A$ 交叉注意力的方式提供了**紧凑且不改变前缀长度/掩码结构**的初始场景索引，避免了上下文膨胀。
- **写入值内容**：视觉 + 动作摘要 > 仅视觉 > 仅动作。仅动作缺少"动作造成何种视觉后果"的接地，仅视觉则缺少"是谁造成的"这一区分线索，验证了"动作—视觉后果"联合编码的设计动机。
- **记忆秩**：32 / 64 / 128 三档中，秩越大越好，128 为实验默认；说明任务所需的联想容量较大，但状态尺寸仍与回合长度无关。
- **跨回合记忆携带**：允许记忆跨回合保留时性能进一步提升（或至少不退化），提示该机制不仅编码单回合情节，也可能承载任务级/环境级的稳定关联。
- **定性失败模式**：基于每任务 50 组同种子配对 rollout 的人工标注与 Holm 校正检验，MemBodied 相对基线的显著改善主要来自**目标位置回忆失败**与**错误放置**类错误的减少；残余失败更多是抓取失败、动作执行不稳等与记忆无关的底层控制问题。

## 8. 局限性与未来工作

- **评测范围**：RMBench 仅选取 9 个任务中的 5 个，M$^{(n)}$ 类只覆盖 2 个任务；真实机器人每任务仅 20 次 rollout，统计置信区间较宽，跨本体与跨任务的泛化性仍有待验证。
- **对比公平性**：NativeMEM 与 μVLA 均为本地适配版本，作者明确声明 π0-μVLA 的低分只反映在当前训练配方下未能学到有效循环策略，**不应解读为对 μVLA 方法本身的一般性比较**；π0-Hint 使用模拟器特权文本，仅作参考而非上界。
- **锚点设计**：固定初始场景锚点在长回合或场景被大幅改变后可能失效；是否应支持锚点的在线更新、多锚点或事件触发式锚点，文中未给出方案。
- **容量与可扩展性**：固定秩的联想矩阵在需要大量离散事实或极长回合时的饱和行为未做压力测试；记忆参数与动作网络联合端到端训练，但未分析记忆写入对训练稳定性的长期影响。
- **资源透明度**：未报告 GPU 总数、总训练时长/GPU 小时与总能耗，复现与成本评估受限。
- **未来方向**（由方法与局限可自然推出）：将记忆扩展到多任务/多本体共享、引入层次化或可增长容量、把延迟写入机制推广到更细粒度的时间尺度，以及在真实长回合任务上做更大规模验证。

## 9. 贡献与总体评价

- **核心贡献**：
  1. 提出一种**尺寸固定、在线更新、按当前策略状态检索**的循环联想情节记忆，写入的是"动作—视觉后果"转移而非孤立观测；
  2. 设计了**因果协调的延迟写入时序**与序列训练方案，使记忆的写/保留/读全部由**原生动作目标**驱动，无需额外记忆监督或离线 token 化流程；
  3. 给出简洁有效的**记忆 token 注入**读出方式，并配套固定情节锚点，在不改变 VLM 前缀长度与注意力掩码的前提下注入情节信息；
  4. 在 RMBench、LIBERO 与真实双臂平台上系统验证了有效性、效率与不损害完全可观测任务的"安全性"。
- **效率优势**：相对需要记忆 tokenizer + 离线缓存 + 分阶段训练的方案，本方法参数量与延迟均低一个数量级（新增参数约为主干 1.26%，推理延迟降低约 92%），更贴近在线机器人部署需求。
- **总体评价**：论文问题定位清晰（时序状态混叠），方法在"不拼接历史"的约束下取得了跨仿真/真实、跨 π0 与 π0.5 主干的一致提升，消融对设计选择给出了合理解释，实验在配对种子与显著性检验上较为严谨。主要保留在于真实机器人样本量偏小、部分基线为本地适配、算力报告不完整，因而其绝对性能与可复现成本仍留有不确定性。
